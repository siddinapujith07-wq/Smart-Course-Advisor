# Smart Course Advisor

Project #13 for Computational Foundations for Artificial Intelligence.

Smart Course Advisor is a React-based academic guidance platform that helps students complete an onboarding survey, understand their strengths, receive personalized course recommendations, generate a timetable, view progress insights, and use an AI-style academic chat assistant.

Live deployment:

```text
https://1777789503812-image-png-pbl-integra.vercel.app
```

## Run in VS Code

Install frontend and backend dependencies:

```powershell
npm run install-all
```

Start the React app:

```powershell
npm run dev
```

Open the local site:

```text
http://localhost:5173
```

## What Is Included

- React frontend with a professional student dashboard UI
- Sign in, sign up, logout, and protected dashboard flow
- Multi-step student onboarding survey
- Personalized course recommendations based on interests, skills, CGPA, completed courses, certifications, and career goals
- Success probability and skill readiness insights
- Timetable planning based on recommended courses and study hours
- Stats dashboard for strengths, weak areas, and progress insights
- CO1 to CO6 mapping page for project evaluation
- AI-style academic advisor chat surface
- Node.js + Express backend for local API usage
- Vercel serverless API for deployment
